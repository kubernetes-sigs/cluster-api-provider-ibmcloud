# CHANGELOG

This folder contains release notes for past releases.

Generate notes for a release with `make release-notes`. The command writes `CHANGELOG/<RELEASE_TAG>.md`. See [Prepare release notes](../docs/book/src/developer/release.md#prepare-release-notes).

[`v0.15.2.md`](v0.15.2.md) is a sample produced by that tool for the latest release. Review the generated file before publishing, including the Highlights placeholder.
